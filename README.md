# 🎙️ E-Portfolio | นายกมลภพ เขาโพธิ์งาม (Kamonphop Khaophongam)

เว็บไซต์แฟ้มสะสมผลงานออนไลน์ (E-Portfolio) สำหรับประกอบการสมัครเข้าศึกษาต่อในระดับอุดมศึกษา **คณะศิลปศาสตร์ / คณะอักษรศาสตร์ สาขาวิชาภาษาญี่ปุ่น** รวมถึงรวบรวมผลงานด้านการฝึกพากย์เสียงตัวละคร (Voice Acting) และทักษะภาษาญี่ปุ่น

> *"เพราะทุกตัวละครมีชีวิต และเสียงของผมคือตัวแทนหัวใจของตัวละคร"*

---

## 👤 ข้อมูลผู้จัดทำ
* **ชื่อ-นามสกุล:** นายกมลภพ เขาโพธิ์งาม
* **ระดับการศึกษา:** ชั้นมัธยมศึกษาปีที่ 6/6 แผนการเรียนศิลป์-ภาษาญี่ปุ่น
* **สถานศึกษา:** โรงเรียนธัญรัตน์
* **เป้าหมายในอนาคต:** ศึกษาต่อด้านภาษาญี่ปุ่นในระดับอุดมศึกษา และก้าวสู่อาชีพ **นักพากย์เสียงมืออาชีพ (Voice Actor)**

---

## ✨ คุณสมบัติของเว็บไซต์ (Features)
* **โครงสร้างครบถ้วน 4 ส่วนหลัก:**
  1. **หน้าแรก (Home):** แนะนำตัวตน แผนการเรียน และเป้าหมายทางอาชีพอย่างโดดเด่น
  2. **แนะนำตัว (Statement of Purpose):** ถ่ายทอดแรงบันดาลใจในการเรียนภาษาญี่ปุ่นและศิลปะการพากย์เสียง
  3. **ผลงาน (Portfolio & Showcase):** การ์ดแสดงผลงานพร้อมระบบกรองหมวดหมู่ (ผลงานพากย์เสียง, ทักษะภาษาญี่ปุ่น, สื่อสร้างสรรค์)
  4. **กิจกรรม (Activities & Experience):** ไทม์ไลน์ประสบการณ์การเรียนรู้และการฝึกฝนทักษะ
* **ดีไซน์ทันสมัย:** ใช้ธีมสีส้ม-ขาว (Orange & White) พร้อมฟอนต์ **Prompt** ที่รองรับภาษาไทยและอ่านง่าย
* **รองรับทุกหน้าจอ (Responsive Design):** แสดงผลได้อย่างเหมาะสมทั้งบนคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ
* **Single-File Architecture:** เขียนโค้ดทั้งหมดรวมอยู่ในไฟล์ `index.html` เพียงไฟล์เดียว ไม่ต้องติดตั้งไลบรารีหรือเครื่องมือเพิ่มเติม

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
* **HTML5** – โครงสร้างเนื้อหาเว็บไซต์
* **CSS3** – การตกแต่งและจัดวาง Layout (Flexbox & CSS Grid)
* **Vanilla JavaScript** – ระบบเมนูสำหรับมือถือและระบบกรองหมวดหมู่การ์ดผลงาน
* **Google Fonts (Prompt)** & **Font Awesome** – ฟอนต์ภาษาไทยและไอคอนประกอบ

## 🚀 วิธีการเปิดใช้งานและเผยแพร่บน GitHub Pages

### 1. การเปิดดูบนเครื่องคอมพิวเตอร์
1. ดาวน์โหลดไฟล์ `index.html` จาก Repository นี้
2. ดับเบิลคลิกที่ไฟล์ `index.html` เพื่อเปิดผ่านเว็บเบราว์เซอร์ (Chrome, Edge, Safari ฯลฯ) ได้ทันที

### 2. การเผยแพร่เว็บไซต์ออนไลน์ด้วย GitHub Pages
1. อัปโหลดไฟล์ `index.html` และ `README.md` ขึ้นไปยัง Repository บน GitHub
2. ไปที่แท็บ **Settings** > เลือกเมนู **Pages** ทางแถบด้านซ้าย
3. ในหัวข้อ **Build and deployment** > **Branch** ให้เลือก `main` (หรือ `master`) และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. รอประมาณ 1–2 นาที ระบบจะแสดงลิงก์ URL ของเว็บไซต์ที่สามารถนำไปแชร์หรือแนบในเอกสารสมัครเรียนได้ทันที

## 📝 การปรับแต่งข้อมูลเพิ่มเติม
หากต้องการอัปเดตลิงก์ผลงานเสียงพากย์หรือช่องทางติดต่อ สามารถเปิดไฟล์ `index.html` และแก้ไขได้ที่จุดต่อไปนี้:
* **ลิงก์ GitHub และโซเชียลมีเดีย:** ค้นหา `https://github.com/kamonphop-example` และแทนที่ด้วย URL โปรไฟล์จริงของคุณ
* **ลิงก์ผลงานแต่ละชิ้น:** แก้ไข `href="..."` ภายในการ์ด `<article class="project-card">` เพื่อเชื่อมโยงไปยังคลิปเสียงบน YouTube หรือ Google Drive
* **อีเมลติดต่อ:** แก้ไขในส่วน `<footer>` ด้านล่างสุดของไฟล์
